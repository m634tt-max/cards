# Карточки — английский (PWA)

Приложение для изучения английских фраз по карточкам с картинками.
Работает офлайн, ставится на Android иконкой, данные хранятся только в телефоне.

## Возможности
- Карточка: лицо — картинка + русская подпись; по нажатию переворот, на обороте —
  уменьшенная картинка, фраза на английском, перевод и кнопка озвучки.
- Интервальное повторение: «Не знаю / Трудно / Знаю». Приложение само решает,
  когда показать карточку снова. Забытая карточка возвращается через 3 карточки.
- Свайп вправо — «Знаю», влево — «Не знаю» (после переворота).
- Режим «Просмотр всех» — листание без оценок.
- Профили со своим прогрессом и настройками: детский режим (крупный шрифт,
  две кнопки), обратный режим (сначала английский), автоозвучка.
- Правка карточки: текст, промпт, замена картинки.
- Колода без картинок (deck.json или вставка текста из буфера) и мастер «Добавить картинки»:
  промпт → Шедеврум → галерея → карточка; картинка сжимается автоматически.
- Напоминания push-уведомлением в выбранные дни и время (нужен свой бесплатный
  сервер на Cloudflare, инструкция в папке `server`).
- Резервная копия всего (колоды + профили + прогресс) в один zip и восстановление.
- Светлая/тёмная тема.

## Формат колоды (zip)
```
колода.zip
├── deck.json
└── images/
    ├── 01.webp
    ├── 02.webp
    └── ...
```
`deck.json`:
```json
{
  "format": 1,
  "id": "travel-basics",
  "title": "Путешествия",
  "cards": [
    { "id": "01", "ru": "Где находится вокзал?", "en": "Where is the train station?", "image": "images/01.webp" }
  ]
}
```
- У карточки может быть поле `prompt`: промпт для генерации картинки.
- Вместо zip можно импортировать один `deck.json` без картинок.
- `id` колоды — постоянный. Повторный импорт колоды с тем же `id` обновит её,
  прогресс сохранится (сопоставление по `id` карточки).
- Картинки: webp/jpg/png, рекомендуемо 768×768 px, до ~150 КБ каждая.
- Карточка без картинки импортируется, приложение сообщит её номер.
- В корне проекта лежит `demo-deck.zip` для проверки.

## Публикация на GitHub Pages (один раз)
1. Войти на github.com → **New repository** → имя, например `cards`, тип **Public**
   (Pages бесплатно работает только для публичных репозиториев; колоды в репозиторий
   не попадают, они живут в телефоне).
2. **Add file → Upload files** → перетащить **содержимое** папки проекта
   (index.html, папки icons и vendor и т. д.) → **Commit changes**.
3. **Settings → Pages → Source: Deploy from a branch → Branch: main / (root) → Save**.
4. Через 1–2 минуты сайт доступен по адресу `https://ВАШ_ЛОГИН.github.io/cards/`.

## Установка на телефон
1. Открыть адрес в **Chrome** на Android.
2. Меню ⋮ → **Установить приложение** (или «Добавить на главный экран»).
3. Запустить с иконки → «Колоды» → «Импорт колоды» → выбрать zip.

## Обновление приложения
При изменении файлов увеличить номер в строке `const CACHE = 'cards-v1.1.3'` в `sw.js`
и залить файлы заново. Телефон подхватит новую версию после 1–2 перезапусков.

## Озвучка
Используются голоса телефона. Если звука нет: Настройки Android → Язык и ввод →
Синтез речи → Google → установить английский голос. Голос и скорость выбираются в «Ещё».

## Важно про данные
Колоды и прогресс хранятся в браузере. Очистка данных Chrome удалит их —
периодически делайте «Ещё → Сохранить резервную копию».
